# Countersign

Agents prepare emails. Humans approve the exact recipients and content. Resend sends the approved revision and reports its delivery outcome.

[Live app](https://countersign.cristianmartinez.co) · [Agent documentation](https://countersign-docs.cristianmartinez.co)

Reviewer credentials are supplied privately. Agents create and revise emails; a human reviews the exact recipients and content before approving delivery through Resend.
